# Gestão de Funcionários - Startup de Tecnologia

Sistema de gestão de funcionários em HTML, JavaScript e Bootstrap.

# Funcionalidades
- Cadastro, edição e exclusão de funcionários
- Classe `Funcionario` com construtor, get/set e `toString()`
- Eventos com funções anônimas e arrow functions
- Relatórios com `filter`, `map`, `reduce` e `Set`: salário acima de R$ 5.000, média salarial, cargos únicos e nomes em maiúsculo

# Como executar (Docker)
    docker compose up -d --build
Acesse http://localhost:8081

# Para parar
    docker compose down
